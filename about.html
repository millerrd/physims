What is Physims?

Physims is a free, open-source collection of interactive browser-based simulations designed specifically for AQA A Level Physics teachers and students. Inspired by PhET and oPhysics, Physims aims to provide a clean, distraction-free environment that teachers can project in the classroom or share with students for independent study.

Every simulation runs entirely in the browser — no installation, no logins, no tracking. Just open and explore.

Curriculum Coverage

Simulations are organised to match the AQA A Level Physics specification:

  • Year 12: Measurements & Errors, Mechanics, Materials, Waves, Electricity, Particles, Quantum
  • Year 13: Periodic Motion, Gravitational Fields, Electric Fields, Electromagnetism, Nuclear Physics, Capacitance, Thermodynamics

Technology

Physims is built with plain HTML, CSS, and vanilla JavaScript — no frameworks, no build steps. Simulations are self-contained JS files that live in the /simulations folder and can be added independently. Styling uses Bulma CSS and Font Awesome via CDN.

Contribute

Physims is open source and welcomes contributions. Whether you want to add a new simulation, improve an existing one, or fix a bug, please see the GitHub repository and read the README for instructions on how to add a new simulation.
